# Passive
Passive items are items you can stow away as a form of "currency". These are:
* [[Ivory Dice]]
* [[Gems]]
* [[Minor Keys]]
* [[Gold Coins]]

## Keys
In addition to minor keys—which simply open locked objects in the manor—there are also Major keys which have special effects as well as more unique keys:

| Key                   | Effect                                                                                                                                                                                                   |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [[Key Card]]          | Opens security doors                                                                                                                                                                                     |
| [[Prism Key]]         | Single use. Unlocking a door in a [[Shop]], [[Bedroom]], [[Hallway]], [[Green Room]], or [[Red Room]] will ensure you draw floorplans of that same colour. Incompatible with Blueprints and Blackprints. |
| [[Silver Key]]        | Single use. Causes the door it unlocks to lead to a room with many doors (three or four exits).                                                                                                          |
| [[Secret Garden Key]] | Single use. Drafts the [[Secret Garden]]. Can only be used on East/West wings.                                                                                                                           |
| [[Garage Key]]        | Opens a car door and trunk found in the [[Garage]].                                                                                                                                                      |
| [[Basement Key]]      | Opens two specific doors found in the [[Underground]].                                                                                                                                                   |
| [[Vault Keys]]        | Opens lockboxes found in the [[Vault]]. Key 370 granted access to a [[Sanctum Key]].                                                                                                                     |
| [[Sanctum Key]]       | Single use. Opens a door in the [[Sanctum]].                                                                                                                                                             |
